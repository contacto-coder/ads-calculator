# Instrucciones para Claude Code

Construye la app descrita en docs/. Lee todos esos documentos antes de implementar. El usuario autoriza crear archivos, instalar dependencias del proyecto y realizar verificaciones locales. Si existe un proyecto, inspecciona su estructura y respeta sus convenciones antes de sustituir herramientas.

Trabaja hasta tener una aplicación funcional. No te detengas en un plan. Resuelve decisiones menores con criterio y documenta las suposiciones. No inventes benchmarks de publicidad, tipos de cambio ni reglas por país. No publiques, conectes cuentas publicitarias ni gastes dinero.

Usa React, TypeScript estricto y Vite si no existe otra base. Usa Vitest para el motor y Testing Library para los recorridos esenciales. Prioriza una interfaz móvil clara y accesible. Separa cálculos puros de presentación. No uses coma flotante binaria para calcular dinero: usa decimal.js y enteros de unidades monetarias mínimas en resultados y almacenamiento.

No llames rentabilidad neta al saldo después de publicidad. No prometas ventas ni plazos. No presentes 5/10/20 % como exigencias de Meta. No añadas IA, autenticación o backend al MVP.

Antes de terminar: ejecutar pruebas, comprobación de tipos y compilación; inspeccionar la interfaz si hay navegador disponible; corregir problemas; entregar comandos de inicio y resumen de verificación. Si no puedes ejecutar una comprobación, informa la limitación concreta. Mantén README actualizado.
