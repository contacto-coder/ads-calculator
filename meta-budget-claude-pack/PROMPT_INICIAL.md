Construye una aplicación web funcional de calculadora de presupuesto para campañas de Meta dirigida a asesores inmobiliarios. Sigue CLAUDE.md y todos los documentos de docs/ de este pack.

Empieza inspeccionando la carpeta. Implementa el MVP completo: asistente de cinco pasos, comisión única o por puntas, escenarios del 5/10/20 %, capacidad financiera opcional, distribución 10/20/30/40 en 30 días, calendario exacto con centavos, resultados explicados, persistencia local e impresión.

La app debe funcionar en español y en celular, sin backend ni cuentas. Usa React + TypeScript + Vite salvo que exista una base compatible que deba conservarse. No hagas una maqueta estática: todos los controles y cálculos deben funcionar. Implementa y ejecuta las pruebas de aceptación. No publiques la app.

Puedes resolver decisiones menores sin preguntarme. Al finalizar, deja la app lista para iniciar localmente, explica cómo abrirla y reporta las verificaciones ejecutadas y cualquier limitación pendiente.
